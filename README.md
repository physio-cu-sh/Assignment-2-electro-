# PTCU Team35 Booking
Arabic RTL team-booking website backed by the existing Supabase project. The database tables and 34-name roster have already been created in Supabase. Each of 7 teams has 5 seats (35 seats total).

Upload `index.html` to a GitHub Pages repository to publish the site. The Supabase publishable key is intended for browser use; do not add a service-role key or admin password to the site.
